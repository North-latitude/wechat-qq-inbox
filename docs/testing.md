# 验收与测试

## 自动化

```powershell
# 后端 + 静态安全 + 前端
.\scripts\check.ps1

# 只跑后端
$env:TEMP="$PWD\.tmp"; .\.venv\Scripts\python.exe -m pytest backend\tests -q

# 只跑安全扫描
.\.venv\Scripts\python.exe scripts\security_check.py

# 前端
pnpm --dir web build

# Android（需要 SDK/JDK17）
cd android
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

### 自动化覆盖

- **鉴权**：无 Token/错误 Token 401；正确 Token 200。
- **只收命中**：空 `matched_rules` 被 422 拒绝；重复 `client_id` 幂等。
- **列表**：来源、会话、搜索、未读、分页游标。
- **已读**：单条、批量、按筛选全部；404。
- **心跳**：从未上报、在线、监听断开、超时离线；`stale` 原因。
- **WebSocket**：ticket 一次性、首帧认证、新消息推送、ping/pong。
- **Android JVM**：规则精确匹配、大小写/空白归一、关键词、禁用、OR、空规则；去重 key 稳定性。
- **静态安全**：Manifest 权限集合、恰好一个 NLS、release 禁明文、无 Accessibility/协议关键字、Token 不进 URL、无 `v-html`、敏感文件忽略。

## 手动回归（每次改动后，约 15 分钟）

1. 页面登录：错误 Token 有明确提示；正确 Token 进入收件箱。
2. 发送一条命中群消息：WebSocket 实时出现，角标 +1。
3. 发送一条未命中消息：页面不出现；诊断 `规则未命中` +1。
4. 关闭唯一规则再发：不出现；诊断提示没有启用规则。
5. 单条已读、批量已读、全部已读；刷新后状态保持。
6. 搜索正文/群名/联系人；来源筛选；只看未读；加载更多。
7. 断开手机网络，发命中消息；恢复网络，自动补传且不重复。
8. 强行停止 App；3 分钟后页面显示离线。
9. 轮换 Token；手机和网页都更新；旧 Token 401。
10. 手机和电脑时钟偏差场景下，确认“最后心跳”不会显示成未来/负数。

## 两周验收（按 Brief）

连续用两周，每天看一次页面和诊断。

- [ ] 特定群/人的消息能在同一页看到，微信/QQ 来源可区分。
- [ ] 非特定消息不出现在页面。
- [ ] 同一条消息不重复。
- [ ] 手机掉线/被杀时，页面能看出来（在线状态/可能掉线提示）。
- [ ] 漏消息时能查清至少一类原因：
  - [ ] 群免打扰/无详情（解析失败/折叠摘要）
  - [ ] 服务被杀/断网（离线/最后心跳）
  - [ ] 规则没命中（`skipped_no_rule`）
  - [ ] 上传失败（`queue_size`/最后上传错误）
- [ ] 规则基本不用天天改（如果天天改，记录是哪类边界问题：群名变化、昵称、关键词太宽/太窄）。
- [ ] 微信/QQ 账号正常，没有安全提醒或限制通知。
- [ ] 页面安装成 PWA，手机桌面可打开。
- [ ] 电脑重启后，后端能按文档恢复；Token 不丢。
- [ ] 备份能恢复（在副本上验证，不覆盖原库）。

达到即停，不再加功能。尤其不要在验收期引入 Hook/协议/自动化“优化”。

## 安全复核（人工，不可省）

- [ ] 没有引入 AccessibilityService、Hook、Xposed/Frida、协议库、NapCat/OneBot/Wechaty。
- [ ] 没有读取微信/QQ 私有数据库或文件。
- [ ] 未命中消息没有正文落库/上传；心跳不含正文和规则 pattern。
- [ ] release APK 不能访问 HTTP；debug 的明文例外是有意的。
- [ ] Token 不在 URL、不在日志、不在 Git。
- [ ] `backend/data`、`.env`、签名文件未被提交。
- [ ] 只通过 HTTPS 暴露；8787 未直接映射公网。
- [ ] 页面无 `v-html`/第三方脚本；CSP 生效。

## 性能/容量

个人使用量级（每天几百条）下 SQLite + 轮询/WS 足够。若长期积累：

- 消息表会持续增长；需要时加归档/导出（后续功能，不在 v1）。
- 页面列表默认 50 条、游标分页；搜索走 `LIKE`，几万条内可接受。
- 采集端 dedup 保留 7 天、hit log 30 天；outbox 只增不删直到上传成功。
